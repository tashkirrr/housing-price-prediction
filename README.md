# Realteak

Realteak is a responsive housing-market exploration demo published from the repository root.

## Pages

- `index.html` — homepage
- `explore.html` — searchable sample city markets
- `countries.html` — sample country list
- `predict.html` — illustrative estimate calculator
- `about.html` — methodology and limitations

The market values and calculator are illustrative demo data, not live prices or appraisals. The website does not currently connect to a global housing-data provider.

## GitHub Pages

The Pages workflow stages only the canonical root pages and their CSS/JavaScript assets. Prototype pages under `docs/`, `frontend/`, and `global-housing-static/` are not published as separate sites. Legacy URLs redirect to the canonical pages.

The site uses plain HTML, CSS, and JavaScript. Run a local static server from the repository root to test navigation and query-string searches.
